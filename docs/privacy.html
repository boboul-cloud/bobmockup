Politique de Confidentialité de Bobmockup

Dernière mise à jour : 22 janvier 2026

L'essentiel : Bobmockup ne collecte aucune donnée. Vos images restent sur votre appareil. Point final.

Qui suis-je ?

Je m'appelle Robert Oulhen, je suis développeur indépendant basé en France et créateur de Bobmockup. J'ai conçu cette application avec un principe simple : votre vie privée n'est pas négociable.

Ce que Bobmockup ne fait PAS

Contrairement à beaucoup d'applications, Bobmockup :

  • ❌ Ne collecte aucune donnée personnelle
  • ❌ N'envoie aucune image sur des serveurs
  • ❌ N'utilise aucun tracker ou outil d'analyse
  • ❌ N'affiche aucune publicité
  • ❌ Ne partage rien avec des tiers

Comment fonctionne Bobmockup ?

Tout se passe sur votre iPhone ou iPad :

  • 📱 Vous sélectionnez une capture d'écran depuis votre bibliothèque
  • 🎨 Vous créez votre mockup dans l'application
  • 💾 Le résultat est exporté localement sur votre appareil

À aucun moment vos images ne transitent par un serveur externe. Je n'ai littéralement aucun moyen de voir ce que vous créez.

Accès à vos photos

Bobmockup vous demande l'autorisation d'accéder à votre bibliothèque photos. C'est nécessaire pour :

  • Importer les captures d'écran que vous souhaitez transformer
  • Sauvegarder vos mockups si vous choisissez de les exporter vers Photos

Vous pouvez révoquer cette autorisation à tout moment dans Réglages → Bobmockup → Photos.

Achats Premium

Si vous achetez la version Premium :

  • Le paiement est géré intégralement par Apple via l'App Store
  • Je n'ai accès à aucune information bancaire ou personnelle
  • Seul votre statut Premium (oui/non) est enregistré localement sur votre appareil

Données stockées localement

Bobmockup enregistre uniquement sur votre appareil :

  • Votre statut Premium
  • Le nombre d'exportations gratuites utilisées

Ces données ne quittent jamais votre appareil et sont supprimées si vous désinstallez l'application.

Sécurité

Pas de serveur = pas de risque de fuite de données. Vos informations sont protégées par les mécanismes de sécurité intégrés à iOS (chiffrement, sandboxing, etc.).

Vos droits (RGPD)

Puisque je ne collecte aucune donnée, l'exercice de vos droits est simple :

  • Accès : Toutes vos données sont déjà sur votre appareil
  • Suppression : Désinstallez l'application
  • Portabilité : Exportez vos mockups comme bon vous semble

Pour les enfants

Bobmockup est classé 4+ sur l'App Store. L'application ne collectant aucune donnée, elle est adaptée à tous les âges.

Évolutions de cette politique

Si je devais modifier cette politique (par exemple pour ajouter de nouvelles fonctionnalités), je mettrais à jour cette page. La date en haut vous indique la dernière version.
